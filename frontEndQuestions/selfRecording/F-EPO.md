# F-EPO（Front-end performance optimization）前端性能优化篇

### 1. 谈谈你对前端性能优化的理解？
1. **请求数量优化** ：合并脚本和样式表，CSS Sprites（CSS图像合并技术），拆分初始化负载，划分主域
2. **请求带宽优化** ：开启 GZip，精简 JavaScript，移除重复脚本，图像优化，将 icon 做成字体
3. **缓存利用优化** ：使用 CDN（内容分发网络），使用外部 JavaScript 和 CSS，添加 Expires 头，减少 DNS 查找，配置 ETag，使 Ajax 可缓存
4. **页面结构优化** ：将样式表放在顶部，将脚本放在底部，尽早刷新文档的输出
5. **代码校验优化** ：避免 CSS 表达式，避免重定向
6. 浏览器**缓存机制**的优点有：
   1. 降低服务器压力，减少请求次数。
   2. 提升性能，本地资源加载比请求服务器快。
   3. 减少带宽消耗，产生很小的网络消耗。
### 2. 网站 TDK 三大标签 SEO 优化
网站 **TDK三大标签（Title（标题）、Description（描述）和 Keywords（关键词））** 进行 **SEO（Search Engine Optimization（搜索引擎优化））** 优化，是提升网站在搜索引擎中排名的关键步骤。以下是针对这三个标签的 SEO 优化建议：
1. **Title** 标签优化：
   1. 确保标题准确反映页面内容，同时吸引用户点击。
   2. 将品牌名或网站名放在标题的开始或结束位置，提高品牌知名度。
   3. 使用简洁明了的语言，避免冗长和复杂的句子。
   4. 关键词应自然地融入标题中，避免堆砌和过度优化。
2. **Description** 标签优化：
   1. 简要描述页面的主要内容和特色，吸引用户进一步了解。
   2. 使用有吸引力的语言，激发用户的兴趣。
   3. 在描述中提及目标关键词，但不要重复过多。
   4. 确保描述与页面内容相关，避免误导用户。
3. **Keywords** 标签优化：
   1. 选择与页面内容紧密相关的关键词，避免选择过于宽泛或无关的关键词。
   2. 将关键词按照重要性和相关性进行排序，最重要的关键词放在前面。
   3. 限制关键词的数量，避免过多关键词导致优化过度。
   4. 使用逗号或空格分隔关键词，保持格式规范。
4. 除了 TDK 标签的优化，还需要**注意**以下几点：
   1. 确保网站内容的质量和原创性，提高用户体验。
   2. 优化网站结构，确保页面之间的链接畅通无阻。
   3. 提高网站的加载速度，避免用户因等待而流失。
   4. 利用社交媒体和其他推广渠道，提高网站的知名度和曝光率。

### 3. 简述几种减少页面加载时间的方法?
常见且有效的策略：
1. **优化图片和媒体资源：**
> - **压缩图片** ：使用专业的图像编辑工具或在线服务来减小图片的文件大小，同时保持视觉质量。
> - **选择适当的图片格式** ：如 GIF、PNG、JPEG 和 WebP，每种格式都有其适用场景，需要根据具体需求来选择。
> - **使用懒加载** ：对于非首屏或用户滚动后才能看到的图片，采用懒加载技术，只在需要时加载，以减少初始加载时间。
1. **优化代码和资源文件：**
> - **压缩和合并 CSS、JavaScript 文件** ：通过工具如 UglifyJS、Terser 等来压缩代码，同时合并多个文件以减少 HTTP 请求次数。
> - **使用 CDN** ：内容分发网络（CDN）可以确保用户从最近的服务器获取资源，从而加快加载速度。
> - **缓存** ：利用浏览器缓存机制，将资源缓存在本地，减少重复请求。
1. **减少 HTTP 请求：**
> - **合并请求** ：通过合并多个 CSS、JavaScript 文件或者通过雪碧图（CSS Sprites）合并小图标来减少 HTTP 请求的数量。
> - **使用 HTTP/2** ：HTTP/2 协议支持**多路复用**，可以在一个连接中并行处理多个请求，从而显著提高加载速度。
1. **优化服务器响应：**
> - **启用服务器端的 Gzip 压缩** ：压缩传输的数据，减少网络传输的带宽需求。
> - **优化数据库查询** ：减少不必要的数据库操作，优化查询语句，提高查询速度。
1. **使用异步和延迟加载：**
> - **异步加载** ：对于非关键资源，如广告、统计脚本等，可以使用异步加载方式，避免阻塞主线程。
> - **延迟加载** ：对于非首屏内容或用户交互后才需要的资源，可以延迟加载，提高首屏加载速度。
1. **代码拆分和按需加载：**
> - **代码拆分** ：将大型代码库拆分成较小的块或模块，根据需要加载，避免不必要的资源浪费。
> - **按需加载** ：根据用户的交互或路由变化，动态加载所需的代码和资源。
1. **优化前端渲染：**
> - **使用虚拟滚动** ：对于大量数据的列表或表格，使用虚拟滚动技术，只渲染视口内的数据，提高渲染性能。
> - **避免重绘和重排** ：通过优化 CSS 选择器和布局，减少浏览器的重绘和重排操作，提高渲染速度。
